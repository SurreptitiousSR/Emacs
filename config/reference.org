* Key Bindings

|-----------+-------------------------------|
| C-x C-f   | Open file (counsel)           |

* Org TODO States
Defined in =config/org-config.el=:
#+BEGIN_SRC text
TODO → IN-PROGRESS → BLOCKED → DONE
#+END_SRC
Cycle with =C-c C-t= in any org buffer.
